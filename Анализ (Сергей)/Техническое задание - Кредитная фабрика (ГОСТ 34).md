# 1. Общие сведения
### 1.1. Наименование  системы
**Полное наименование системы**: автоматизированная информационно-аналитическая система полного цикла кредитования для субъектов малого и среднего предпринимательства.
**Сокращённое наименование**: кредитная фабрика.
Далее в документе будет использовать термин *"система"*.
### 1.2. Наименование заказчика и исполнителя
**Заказчик**: Кредитный департамент, отдел кредитования малого и среднего бизнеса.
**Исполнитель**: Департамент информационных технологий, отдел программирования и автоматизации банковских процессов.

# 2. Цели и назначение создания автоматизированной системы
### 2.1. Цели создания системы
Цели для которых разрабатывается система:
- Уменьшение ручного труда за счёт автоматического сбора данных;
- Уменьшение количества ошибок. Исключение ручного заполнения полей снижает вероятность ошибок (описки, дубли, неверные реквизиты);
- Упрощение принятия решения. Кредитный комитет и все ответственные сотрудники могут принимать решение внутри кредитной фабрики, без очных встреч и бумажного документооборота. При определённых условиях решение принимается без участия сотрудников, тем самым уменьшая трудозатраты отдела кредитования;
- Упрощение подачи заявки на кредит. Клиент первично авторизируется через ЕСИА Госуслуги, все данные собираются автоматически и ему не нужно заполнять свои персональные данные;
- Повышение качества принятия решений. Комитет видит полную, актуальную и выверенную информацию из всех систем.
### 2.2. Назначение системы
Система предназначена для:
- Автоматизации полного цикла кредитования МСП от первичной идентификации клиента до принятия решения кредитным комитетом;
- Предоставления клиенту максимально простого канала подачи заявки на кредит;
- Автоматическое создание/обновление в АБС карточки клиента ФЛ и ИП;
- Автоматическое создание заявки на кредит в АБС;
- Сбор данных из различных агрегаторов о клиенте, для дальнейшего анализа данных;
- Автоматический отказ или одобрение заявки для заранее описанных условий;
- Уменьшение ошибок связанных с ручным вводом;
- Перевода работы кредитного комитета в полностью цифровой формат без очных встреч и бумажного документооборота.
# 3. Характеристика объектов автоматизации
### 3.1. Область автоматизации

Система «Кредитная фабрика» автоматизирует бизнес-процессы предкредитной обработки и принятия решений по кредитным заявкам индивидуальных предпринимателей и юридических лиц.  Система имеет класс защищённости К3 и 3 уровень защищённости персональных данных, что соответствует требования нормативной документации по безопасности информации.

**Основные автоматизируемые процессы:**
1. **Первичный сбор и верификация данных клиента**
    - Получение данных из ЕСИА (для авторизации и получения первичной информации);
    - Автоматическое заполнение анкеты данными из внешних источников;
    - Проверка базовых критериев (возраст, регион регистрации, срок деятельности и т.д.).
2. **Комплексная проверка контрагента**
    - Проверка статуса ИП/ЮЛ в реестрах ФНС;
    - Проверка наличия в реестре МСП;
    - Анализ арбитражных дел и исковой нагрузки;
    - Проверка реестра недобросовестных поставщиков;
    - Проверка реестра дисквалифицированных лиц;
    - Анализ задолженностей перед ФНС и ФССП;
    - Контроль прохождения проверок ПОД/ФТ;
    - Проверка наличия банкротства.
3. **Кредитный скоринг и принятие решений**
    - Запрос кредитных историй из БКИ (НБКИ, ОКБ)
    - Расчет кредитного рейтинга
    - Автоматическая оценка кредитной нагрузки
    - Маршрутизация заявок (автоматическое одобрение / кредитный комитет / отказ)
4. **Интеграция с банковскими системами**
    - Создание/обновление анкет клиента в АБС ЦФТ
    - Регистрация кредитных заявок
    - Проверка наличия расчетных счетов
    - Проверка действующих кредитов
    - Получение Н6
    - Получение размера капитала банка

### 3.2. Основные бизнес-правила

**Подача кредитной заявки включает следующие этапы**:
1. **Идентификация** — аутентификация через ЕСИА, получение первичных данных
2. **Валидация** — проверка соответствия базовым критериям
3. **Инициация заявки** — клиент заполняет параметры кредита на сайте банка
4. **Сбор данных** — автоматическое получение информации из внешних источников
5. **Комплексная проверка** — анализ реестров, арбитража, задолженностей
6. **Кредитный скоринг** — запрос БКИ, расчет рейтинга
7. **Принятие решения** — автоматическое или через кредитный комитет
8. **Оформление** — создание заявки в АБС, подписание документов

**Альтернативные потоки**:
- Отказ на этапе первичной валидации
- Отказ по результатам проверки контрагента
- Направление на кредитный комитет
- Приостановка заявки (клиент не завершил формирование)

![[Алгоритм работы (упрощённый).pdf]]

**Критерии первичного отсева:**
- Возраст клиента: до 70 лет на момент окончания кредита
- Регион регистрации: Сахалинская область
- Срок регистрации: не менее 3 месяцев
- Статус ИП: действующий в данный момент
- Наличие в реестре МСП: обязательно

**Финансовые ограничения:**
- Сумма исков в арбитражных судах: < 300 000 руб.
- Задолженность перед ФНС: < 100 000 руб.
- Задолженность по ФССП (действующая): < 100 000 руб.
- Просроченная задолженность: ≤ 10 дней
- Текущая просроченная задолженность: отсутствует
- Рейтинг БКИ: ≥ 700 баллов

**Маршрутизация заявок:**
- Сумма ≤ 1 000 000 руб. → автоматическое рассмотрение
- Сумма > 1 000 000 руб. → обязательное предоставление выписок по счетам → направление на КК
- Наличие экспресс-кредитов → направление на КК
- Сумма > 3 000 000 руб. → уведомление сотрудников (без формирования заявки)
### 3.3. Используемые информационные системы

**DaData** — сервис для обработки и стандартизации данных, который автоматизирует проверку, обогащение и заполнение информации о клиентах, адресах, организациях:
- Статус организации (ОПФ) и текущее состояние
- Дата присвоения ОГРН
- Адресные данные
- Коды ОКАТО, ОКОПФ, ОКПО, ОГРН, ОКВЭД

**ИРБИС** — система проверки государственных реестров:
- Реестр МСП
- Реестр недобросовестных поставщиков
- Реестр задолженностей перед ФНС
- Данные ФССП (исполнительные производства)
- Дописать пункты ParserAPI

**ParserAPI** — агрегатор данных арбитражных судов:
- Поиск дел по ИНН (в роли ответчика)
- Получение информации о ходе исполнения дел
- Расчет суммы исковых требований

**БКИ (НБКИ, ОКБ)** — бюро кредитных историй:
- Кредитная история заёмщика
- Рейтинг заёмщика
- Информация о действующих обязательствах

**АБС ЦФТ** — автоматизированная банковская система:
- Создание/обновление клиентских анкет (ФЛ, ЮЛ)
- Регистрация кредитных заявок
- Проверка наличия расчётных счетов
- Контроль ПОД/ФТ
- Проверка действующих кредитов
- Получение данных Н6 и капитала банка

**ЕСИА** — единая система идентификации и аутентификации:
- Первичная аутентификация клиента
- Получение согласий на обработку данных
- Запрос согласия клиента на формирование запросов в БКИ
